How the Layout Works

This page uses flexbox to center the main section horizontally and vertically inside the container. The container is about 80% of the viewport height while the menu has its own fixed height and width.

Screen Sizes

The background image is set to cover the entire screen no matter the device size as it won't change with the resize options though the menu is fixed and may not fit on smaller screens.

Features

The Task Options links can redirect users to a different section of the website though yet it is not fully implemented.

Whenever you hover over a link you will see its highlight effect.

The background image fills the page behind the content.
